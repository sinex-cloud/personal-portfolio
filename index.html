Featured project · Sep. 2026 - Oct. 2026

CI/CD Delivery Pipeline on GCP

A push to main goes live on two Google Cloud servers in under two minutes, with no manual steps.

View on GitLab

What I built

  • Automated delivery of a containerized FastAPI service to two GCP VMs, so every push to main is tested, published to Docker Hub and deployed in under two minutes, with a three-stage GitLab CI/CD pipeline
  • Made deployments repeatable and safe to retry by writing idempotent Ansible roles that install Docker, run the exact image tagged with the commit SHA and confirm each release through a health check
  • Provisioned the infrastructure as code with Terraform (two Compute Engine VMs and a tag-scoped firewall rule) and kept credentials out of the repository with protected GitLab CI/CD variables and a dedicated deploy SSH key

Decisions I can defend

  • Firewall scoped by network tag. It opens ports 22 and 80 only on the two web VMs, never on other machines in the shared GCP project.
  • One image per commit. Images are tagged with the commit SHA, so each server runs a version that traces back to exactly one commit.
  • Secrets never touch the repo. The Docker Hub token and a dedicated deploy key live in protected GitLab CI/CD variables.
  • Free-tier sizing. e2-micro VMs in us-central1 keep the running cost to a few cents a day.
